Who I am

I'm a Data Analyst and Python Developer based in Gurugram, India, currently pursuing my MCA at K.R. Mangalam University. My work bridges analytical inquiry and software engineering — extracting, cleaning, and modeling data to turn complex metrics into actionable business insights.

My toolkit spans the complete data lifecycle: hands-on experience in raw data extraction and wrangling using Python, Pandas, and NumPy, exploratory analysis and charting with Matplotlib, and interactive dashboards in Power BI, Tableau, and MS Excel. On the backend and data engineering side, I design scheduled ETL pipelines, integrated PostgreSQL databases using SQLAlchemy, write complex SQL queries using window functions and subqueries, and build REST APIs with MongoDB and SQL.

I also apply machine learning fundamentals with Scikit-learn, building time-series regression models and implementing financial risk analytics including Value at Risk (VaR), Expected Shortfall, and strategy backtesting.
